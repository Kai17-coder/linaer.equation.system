Key Forms of Linear Equation

Standard form: ax + by = c. Each equation in this solver uses this form, with one coefficient per unknown.

Slope-intercept form: y = mx + b. Here m is the slope and b is where the line crosses the y-axis.

Point-slope form: y − y₁ = m(x − x₁). Use it when you know one point and the slope.

General (n unknowns) form: a₁x₁ + a₂x₂ + … + aₙxₙ = b.

Matrix form: AX = B. Solving with the inverse gives X = A⁻¹B, which is exactly what this page computes.

Graphing two equations in two unknowns: 3 possible cases

Case 1: One solution

The lines intersect at exactly one point. The system is consistent and independent, det(A) ≠ 0, and the inverse exists.

Case 2: No solution

The lines are parallel: same slope, different intercepts, so they never meet. The system is inconsistent and det(A) = 0.

Case 3: Infinitely many solutions

Both equations describe the same line, so every point on it is a solution. The system is consistent and dependent, and det(A) = 0.

In Cases 2 and 3 the matrix has no inverse, so this solver reports “no unique solution”.
